<Intro>
  Make your React components and data available to every MDX page.
</Intro>

Create a component and some data:

```tsx title="docs/authoring/Example.tsx"
'use client'

import { useState } from 'react'

export function Example({ initialCount }: { initialCount: number }) {
  const [count, setCount] = useState(initialCount)
  return (
    <button className="rounded border px-3 py-2" onClick={() => setCount(count + 1)}>
      Count: {count}
    </button>
  )
}
```

```json title="docs/authoring/Example.json"
{ "initialCount": 3 }
```

Register them in `docs.config.ts` at your repository root:

```ts title="docs.config.ts"
import { Example } from './docs/authoring/Example'
import example from './docs/authoring/Example.json'

export default {
  components: { Example },
  scope: { example },
}
```

Then use them directly in MDX:

```md
<Example initialCount={example.initialCount} />
```

result:

<Example initialCount={example.initialCount} />

Click the counter to increment it.

- The CLI finds `docs.config.ts` in the current working directory. Use `--config path/to/config.ts` or `DOCS_CONFIG` for another path. Both `components` and `scope` are optional.
- Add `'use client'` to interactive component modules and pass serializable props. Keep the configuration on the server. Install any imported packages in your repository, including in CI.
- Website builds support CSS imports; include external component files in your Tailwind sources if needed. HTML fragments only render the initial HTML, without hydration or stylesheets.
