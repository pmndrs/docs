<Intro>
  Make your React components and data available to every MDX page.
</Intro>

Create a component and some data:

```tsx title="docs/authoring/Example.tsx"
'use client'

import { useState } from 'react'

export function Example({ initialCount }: { initialCount: number }) {
  const [count, setCount] = useState(initialCount)
  return (
    <button className="rounded border px-3 py-2" onClick={() => setCount(count + 1)}>
      Count: {count}
    </button>
  )
}
```

```json title="docs/authoring/Example.json"
{ "initialCount": 3 }
```

Register them in `docs.config.ts` at your repository root:

```ts title="docs.config.ts"
import type { DocsConfig } from '@pmndrs/docs/src/docs.config'
import { Example } from './docs/authoring/Example'
import example from './docs/authoring/Example.json'

export default {
  components: { Example },
  scope: { example },
} satisfies DocsConfig
```

Then use them directly in MDX:

```md
<Example initialCount={example.initialCount} />
```

result:

<Example initialCount={example.initialCount} />

Click the counter to increment it.

## Configuration and rendering

### Configuration

The CLI looks for `docs.config.ts` in the current working directory. To use another file, pass `--config`:

```sh
npx @pmndrs/docs build docs out --format website --config config/docs.config.ts
```

You can also set `DOCS_CONFIG`. Relative paths resolve from the current working directory. Both `components` and `scope` are optional. A custom component with the same name as a built-in component replaces it.

### Interactive components

Add `'use client'` to component modules that use state, effects, or event handlers. Props passed from MDX must be serializable, such as strings, numbers, arrays, or plain objects.

Keep `docs.config.ts` on the server; it does not need `'use client'`. Install packages imported by your components in your repository, including when building in CI.

### Styles and HTML fragments

Website builds support CSS imports in your components or configuration. For Tailwind classes in external component files, add those files to the sources of your own Tailwind stylesheet and import it from the configuration.

HTML fragments contain only the initial rendered HTML, without hydration or stylesheets. For example, the counter above renders its starting value but does not respond to clicks in a fragment.
