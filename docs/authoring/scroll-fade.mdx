<Intro>
  A fade on the edges of a scroll container, where there is more content to scroll to.
</Intro>

[shadcn's `scroll-fade`](https://ui.shadcn.com/docs/utils/scroll-fade) utility classes, available in any `className`: see its page for every class (`scroll-fade-t`, `scroll-fade-<number>`, `scroll-fade-none`…).

The direction and edge classes (`scroll-fade`, `-x`, `-y`, `-t`, `-b`, `-l`, `-r`, `-s`, `-e`, `-none`) and the sizes up to 24 (`scroll-fade-8`, `scroll-fade-b-4`…) always exist, even for docs that are not scanned for classes. An arbitrary value (`scroll-fade-[15%]`) or a variant (`md:scroll-fade-none`) exists only where the page is scanned, as any Tailwind class.

## Usage

On the element that scrolls, the one with `overflow-y-auto`:

```jsx
<div className="overflow-hidden rounded-2xl border">
  <div className="h-72 scroll-fade overflow-y-auto">
    <div className="flex flex-col gap-1.5 p-1.5">
      <div className="rounded-lg bg-surface-container px-3 py-2.5">Item 1</div>
      <div className="rounded-lg bg-surface-container px-3 py-2.5">Item 2</div>
      <div className="rounded-lg bg-surface-container px-3 py-2.5">Item 3</div>
      <div className="rounded-lg bg-surface-container px-3 py-2.5">Item 4</div>
      <div className="rounded-lg bg-surface-container px-3 py-2.5">Item 5</div>
      <div className="rounded-lg bg-surface-container px-3 py-2.5">Item 6</div>
      <div className="rounded-lg bg-surface-container px-3 py-2.5">Item 7</div>
      <div className="rounded-lg bg-surface-container px-3 py-2.5">Item 8</div>
      <div className="rounded-lg bg-surface-container px-3 py-2.5">Item 9</div>
      <div className="rounded-lg bg-surface-container px-3 py-2.5">Item 10</div>
    </div>
  </div>
</div>
```

At the top, only the bottom edge fades; mid-scroll, both; at the end, only the top. Content that does not overflow does not fade. In browsers without `animation-timeline: scroll()`, both edges fade, always.

The fade is a mask: it dissolves the content, and the border of the element with it. For a crisp border, put it on a wrapper.
