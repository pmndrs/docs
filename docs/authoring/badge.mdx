</Intro>

A label-less [shields.io](https://shields.io/badges/static-badge) static badge (`/badge/-<message>-<color>`) is rendered as a `Badge` too, linked or not. Its color is dropped:

```md
[![](https://img.shields.io/badge/-storybook-%23ff69b4)](https://drei.pmnd.rs/?path=/story/abstractions-positionalaudio--positional-audio-scene-st)
[![](https://img.shields.io/badge/-suspense-brightgreen)](https://r3f.docs.pmnd.rs/api/hooks#useloader)
![](https://img.shields.io/badge/-Dom%20only-red)
```

result:

[![](https://img.shields.io/badge/-storybook-%23ff69b4)](https://drei.pmnd.rs/?path=/story/abstractions-positionalaudio--positional-audio-scene-st)
[![](https://img.shields.io/badge/-suspense-brightgreen)](https://r3f.docs.pmnd.rs/api/hooks#useloader)
![](https://img.shields.io/badge/-Dom%20only-red)

Any other shields.io badge (npm version, downloads, discord...) stays an image.
