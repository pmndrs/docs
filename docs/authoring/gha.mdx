<Intro>
  GitHub-style alerts with multiple severity levels.
</Intro>

Aka. ["GitHub alerts"](https://github.com/orgs/community/discussions/16925)

Callouts compose shadcn `Card` parts with each kind's Material background and matching
foreground. The icon-and-label header sits above full-width rich content, using the standard
Card spacing. They remain static editorial notes, so reading an article does not trigger an
assertive screen-reader announcement.

```md
<Gha keyword="NOTE">Highlights information that users should take into account, even when skimming.</Gha>
```

or better:

```md
> [!NOTE]
> Highlights information that users should take into account, even when skimming.
```

result:

> [!NOTE]
> Highlights information that users should take into account, even when skimming.

---

We also support: `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]`, `[!CAUTION]`

result:

> [!TIP]
> Optional information to help a user be more successful.

> [!IMPORTANT]
> Crucial information necessary for users to succeed.

> [!WARNING]
> Critical content demanding immediate user attention due to potential risks.

> [!CAUTION]
> Negative potential consequences of an action.

---

The `title` prop overrides the label derived from `keyword` (icon and background still follow the keyword). Only available via the JSX form:

```md
<Gha keyword="TIP" title="MCP-server">Browse these docs from your MCP-compatible client.</Gha>
```

result:

<Gha keyword="TIP" title="MCP-server">Browse these docs from your MCP-compatible client.</Gha>

Rich Markdown also works inside a callout:

> [!NOTE]
> Keep **headings, links and lists** in your existing authoring content:
>
> - Read the [Keypoints](keypoints) before starting.
> - Open the [sandbox examples](codesandbox) to try the ideas.

Custom labels wrap in full, and rich blocks retain their structure:

<Gha keyword="TIP" title="Before sharing a sandbox, check its dependencies and document the environment needed to reproduce the example">

### Reproduce the example

Run the example locally before sharing it:

```sh
pnpm install
pnpm dev
```

- Document the requirements.
  - Include the supported Node.js version.
- Link to the [sandbox examples](codesandbox).

</Gha>
